# Sonuvi 0.4.9 划词菜单稳定性修复

日期：2026-10-19。版本：0.4.9（22）。包含 0.4.8 的朗读预热和截图优化，以及原有离线模型和 28 个英文音色。

## 诊断证据

检查时，当前连接机器的 /Applications/Sonuvi.app 为 0.4.7；划词按钮开关开启、应用排除列表为空、首次设置已完成。没有读取或修改 API Key、用户选中文字或系统权限数据库。

源码中的明确失效条件：
- 只在松开鼠标 220ms 后读取一次 AXSelectedText，应用延迟更新选区时直接漏掉。
- 依据翻译窗口的 isVisible 和 frame 排除区域，没有判断窗口是否被其他应用遮挡。这会令原窗口位置上的其他应用划词被误拦截。
- 分别异步处理鼠标按下/松开，并在执行时读取实时鼠标位置，会丢失事件发生时的坐标。
- 任何应用激活通知都取消当前取词，可能误取消同一应用的延迟激活事件。
- 点击菜单后全局屏蔽 0.5 秒，会误拦截紧接着进行的新划词。

## 修复

- 合并全局鼠标事件监听，按原始事件顺序和坐标处理；本应用事件由本地监听处理，不再用被遮挡窗口的矩形区域屏蔽外部划词。
- 每次真实手势使用独立请求标识，旧请求、重复 mouse-up、滚动、取消、菜单操作和切换应用不会重新弹出旧菜单。
- 120/180/300ms 有界重试，成功即返回；AX IPC 放到串行后台队列。被禁用、应用被排除、截图期间或取消后，结果不会显示。
- 支持 selected range + AXStringForRange / AXValue 取词路径；排除密码输入框、空选区及非法 UTF-16 范围。
- 去掉全局半秒冷却；新拖选立即有效。支持拖选、双击和 Shift 点击选区。
- 唤醒、用户会话恢复和切换桌面后重建监听；安装失败时通过原有状态轮询重试。
- 添加仅记录权限/监听状态的诊断日志，不记录文本、剪贴板或 API Key。

## 验证

- 89 项原有核心检查通过。
- 29 项新的划词回归检查通过：延迟选区、取消、切换应用、同应用晚到激活、连续手势、重复 mouse-up、UTF-16 边界、有限重试和主线程响应。
- 应用 codesign --verify --deep --strict 通过。
- DMG 校验结果见 work/v049-dmg.log。

当前没有可用的桌面自动化接口，未在用户实际出问题的应用中做真人拖选复现，不能据此声称覆盖所有应用。部分应用不向辅助功能提供选中文字时，仍需显式快捷键的剪贴板回退或截图翻译；自动划词不会偷偷模拟复制。

## 安装

退出旧版，将 DMG 中 Sonuvi 拖入 Applications 替换后重新打开。保持 bundle ID 不变，未清除偏好、API Key、统计或授权。新的应用没有替用户安装到 /Applications。
