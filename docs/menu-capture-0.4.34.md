# 菜单展开期间截图修复

0.4.34 / build 47，2026-10-23。

0.4.33 仅提前冻结桌面，未解决原生菜单追踪循环下快捷键与主队列任务延后。现在在已授权辅助功能时使用 common-mode 事件 tap 接收截图组合键；截图回调通过 common-mode run loop 交付，保存像素后才退出本应用菜单，随后进入框选。辅助功能不可用时保留 Carbon 快捷键后备，不主动请求新权限。普通按键不被拦截，长按不重复截图，录制快捷键时暂停。

实测 `--menu-capture-test` 创建本应用的原生 NSMenu，中英文测试条目；在菜单保持展开时发送自定义截图键，确认快捷键与截图回调都在菜单关闭前执行。之后自动在真实框选层拖动，裁剪冻结画面并识别两条菜单文字，确认不重复触发。三项通过，未读取其他应用聊天或输出桌面图像。

核心 109 项、编辑 26 项、选区 98 项及 OCR 冻结裁剪/识别/取消回归通过。此次验证覆盖本机原生菜单和真实框选，不代表所有第三方应用定制菜单或其他 macOS 版本已逐项验收。
