# Sonuvi 0.4.16 — 安装、重装与权限

## 标准 DMG

完整离线 DMG 内置本地模型及 28 个英文音色。双击挂载后打开 Finder 安装窗口，将 Sonuvi.app 拖到 Applications。已有同名应用时，替换/保留/取消由 Finder 原生对话框处理；更新前先退出旧版。没有自制覆盖安装器，也不修改其他应用。

## 启动与权限

- 首次使用仍进入 onboarding。
- 已完成 onboarding 后，启动和无窗口时重新打开默认进入设置，不再弹出空翻译窗口。
- 辅助功能或屏幕录制缺失时，自动定位“设置 → 权限”。
- 设置新增权限分类，顶部玻璃卡片显示待授权、处理中、已就绪状态；已授权项目显示圆形勾选状态。
- 返回应用或系统提示退出并重新打开后，保留设置/引导来源并返回原权限页面。

## 重装恢复

通过版本号与应用目录的设备号、文件节点、创建时间标记安装实例；同版本替换也可识别。首次迁移使用既有 onboarding / 授权请求记录判断是否为已有用户。仅在 Applications 中运行的新安装实例、已有用户且至少一项权限失效时自动恢复。

按用户要求，对本应用执行两个独立重置：

```
tccutil reset Accessibility com.wusir.musetranslate
tccutil reset ScreenCapture com.wusir.musetranslate
```

采用系统提供的权限重置机制，不编辑 TCC 数据库，也不自动授予权限。重置前先确认重启助手就绪；两个服务分别记录结果。一项失败仍尝试另一项；部分成功会重启以清掉进程缓存，并在返回后告知未成功的项目。安装标记在尝试前持久化，同一安装不会重复自动清理；已正常保留两项授权的更新不触发清理。界面保留“重新配置权限”作为手动恢复入口。

测试仅使用隔离偏好、注入的命令执行器和无害子进程，不会重置当前设备的真实权限。测试覆盖首次安装、旧版迁移、重装、普通重启、已授权更新、部分失败与防循环。

Apple 文档： https://developer.apple.com/documentation/xcode/resetting-access-to-protected-resources-in-macos

当前使用临时签名；跨版本是否保留权限仍由 macOS 判定。
