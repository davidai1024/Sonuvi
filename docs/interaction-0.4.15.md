# Sonuvi 0.4.15 — 快捷键交互与引导布局

按用户提供的 14 秒参考视频统一设置与 onboarding 的快捷键交互：

- 点击一行显示选中背景，大按键预览对应已保存的组合。
- 点击右侧快捷键框开始录制，单层蓝色圆角描边与状态文字明确提示录制中。
- 移除 NSButtonCell 绘制，避免原生高亮、系统焦点环与自定义边框叠加成横条；支持非激活窗口首次点击。
- 当前按下的修饰键和字母实时映射到大按键，不与旧组合键的修饰键混合。
- 松开字母键提交；Esc、点击外部、切换窗口或离开页面取消。
- 固定预览区和提示区高度，切换状态不改变卡片高度。
- 默认组合与用户已有自定义组合保持不变；冲突校验和原有全局快捷键暂停机制保留。

所有 onboarding 页面的右侧内容由同一可滚动居中容器承载。以窗口实际可用高度居中，移除固定 450 pt 的内容高度；内容较高时保留自然高度并从顶部滚动，每次换页重置滚动位置。

验证：101 项核心检查，38 项偏好交互及布局检查。包含深浅外观、短/长内容布局、实际设置与 onboarding 页面中的录制、唯一选中、保存以及离页取消。测试仅向自身测试窗口发送事件，不修改实际快捷键、授权或 API Key。
