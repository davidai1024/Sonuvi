# Screenshot workspace — 0.4.49

The reference interaction is a frozen screenshot work area: the desktop outside the selection stays dim, eight handles remain visible, and a compact toolbar sits below the selection or inside its lower edge when space is limited. The translated result can be dragged without resending its text. Resizing changes the captured source area and reruns local OCR, reusing completed translations with the same text and target language. Reselect uses the same frozen desktop; start a new screenshot to capture a changed page.

Automatic detection chooses one target language for the selected area; text already in that target remains untouched, including English filenames in a Chinese interface. The toolbar supports source and target language selection, language swapping, an original comparison switch, native text-selection mode, image copy, pinning, reselection, opening the translation window, text copy, and closing. Holding Option temporarily reveals the original while the workspace has focus. Command-C copies the image unless a native text editor handles the selected text. Pinned mode reduces the window to the result and toolbar and removes the dark desktop backdrop, allowing work in other apps. Escape and the close button remove all workspace panels and cancel pending work.

Vision observations are split at large inter-word gaps before paragraph grouping so table cells do not become one sentence across columns. Each OCR line retains its own source bounds. Rendering removes only those source-text strips, then draws the translation with a font estimated from both original glyph width and height. Dominant exact background colors and sampled ink colors preserve flat button surfaces and light-on-dark labels. Expansion stops before neighboring OCR text. Numeric metadata, file sizes, standalone variables and short uppercase identifiers retain their source pixels. Long translations remain bounded with scrolling, and clipped image export remains disabled.

During recognition and translation, a centered status indicator appears over the selected image. The translated layout appears after the validated response completes, avoiding repeated resizing while tokens arrive. Source text is sent in an inert JSON envelope under a screenshot-specific translation prompt. Screenshots, recognition geometry and background samples stay local. Changing language, selection, closing or starting another capture invalidates prior callbacks; completed local labels are cached only within the current workspace.

Acceptance uses generated file-list and paper-diagram scenes through the production native workspace. Their offline response maps are explicitly test fixtures; they validate OCR geometry, rendering and controls, not the quality or availability of DeepSeek. Live provider checks are recorded separately. No third-party reference screenshot is sent to a provider by the fixture tests.

Limits: the workspace is a frozen capture, and it translates recognized horizontal text rather than reconstructing a document model. Complex photographic backgrounds, vertical text and missing OCR glyphs still require separate handling. The reference's unrelated formula extraction, summarization and writing tools are not claimed as Sonuvi features.
