# Sonuvi 0.4.12 — 辅助功能授权修复

更新后若辅助功能已打开却无法划词，进入 **设置 → 通用 → 权限 → 修复辅助功能授权**。

按钮只重置 Sonuvi 自己的辅助功能记录，自动重启，再申请授权并打开系统设置。请手动打开 Sonuvi 的辅助功能开关，返回原设置页或引导页；如系统要求退出并重新打开，重启助手会接续。引导页不会自动跳到下一步。

- 不重置屏幕录制、钥匙串、模型、API 设置或其他应用的权限。
- 普通启动和权限轮询不会重置记录；修复只在用户点击时进行。
- 使用系统自带 `tccutil reset Accessibility com.wusir.musetranslate`，不修改 TCC 数据库，不自动授予权限。
- 重启助手就绪后才重置；重置失败或超时保留当前窗口并显示错误。
- 使用一次性、15 分钟有效的恢复标记，新进程重新申请，避免沿用旧进程缓存的授权结果。
- 保留 0.4.11 划词兼容性和 0.4.10 授权返回修复。

当前仍是临时签名。这是授权失效后的恢复入口，不能保证之后每次更新都不再需要授权。若系统拒绝定向重置，会提示手动处理，不会扩大到所有应用。

验证包含重置范围、缺失或错误 bundle ID、跨进程恢复标记、重复/过期恢复、进程失败、超时及主线程响应。使用无害替代进程测试，未重置开发机器的真实权限；真实 macOS 授权交互仍需在安装后确认。
