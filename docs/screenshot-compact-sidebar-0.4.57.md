# 紧凑中文侧栏识别与排版 · 0.4.57

0.4.57（build 70）处理图标与标签间隔较小的导航栏。原文字形末端的浅色抗锯齿像素不再被当作右侧障碍；检测到的导航标签优先在可读范围内保持单行，超长内容仍受实际边界限制。

中文导航文字列会从原截图无损裁出，在本机再次识别并映射回原图坐标，防止识别引擎把图标的字符框分配给真实汉字。很小的深色文字列仅在识别输入中增强，显示与导出的底图保持原始像素。已识别的英文保留整图上下文；空字符框不能作为删除正文的证据。
