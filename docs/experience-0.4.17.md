# Sonuvi 0.4.17 — 模型管理、引导与 API 输入

## 本地模型

- 正常状态显示“模型已就绪，可离线朗读”和“试听声音”。
- 修复、查看文件、移除收进更多菜单；移除仍有确认。
- 完整包不展示旧 Speak11 导入入口。没有内置模型时，只有旧运行环境和指定模型缓存都存在才提供导入。
- 联网下载仅在准备/修复失败后作为备用入口。
- 取消或修复失败的信息与模型当前可用状态分开。现有模型仍能使用时，不再把“已取消”当作模型状态。
- 统一准备策略：优先内置资源，其次完整旧环境，再联网下载。未声称本轮已验证联网下载全流程。

## 重新运行 onboarding

删除应用本体不等于清除用户配置，既有 onboarding 完成记录保留。更新/重装沿用设置；缺权限时进入权限页。

通用设置新增“使用引导 → 开始引导”。重看引导从欢迎页开始，现有设置、API Key、音色等保留。可随时“返回设置”；关闭并重开应用可以继续未完成的引导。首次使用仍须按原流程完成必需步骤。

## API Key 焦点

设置和 onboarding 使用同一原生 NSSecureTextField 组件。点击外部、Esc、Return 可结束编辑；仅结束编辑不会写入钥匙串，也不会直接跳到 onboarding 下一页。未保存的输入保留在当前界面。输入框不在 SwiftUI 更新时强制抢回焦点。离开窗口或移除组件时清理事件监听。原生安全输入与系统编辑命令保留。

验证使用测试窗口和合成文本，不读取或修改用户真实 API Key。
