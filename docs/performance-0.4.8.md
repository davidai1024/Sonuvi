# Sonuvi 0.4.8 性能迭代

## 改动

- 独立 Kokoro 环境在启动后、首次安装完成后和唤醒后无声预热。
- 每 120 秒轻量保活；已预热语言不重复合成。应用退出后停止保活，引擎保留原有 10 分钟空闲退出机制。
- 预热使用固定示例，不读取选中文字，不播放或保存音频；与实际朗读共享模型。
- macOS 15.2+ 使用轻量 AppKit 选框，拖动时不截图、不 OCR；暂停划词弹条。
- 截图以 CGImage 直接交给后台 Vision，省去进程启动和 PNG 文件读写。旧系统保留兼容路径。
- 图像截取完成即显示识别状态，随后识别、自动翻译。
- 取消、关闭窗口或编辑原文会使旧识别任务失效。

## 本机测量（2026-10-18）

Apple Silicon、macOS 26.6.2、固定英文样本，不播放音频。以下是请求到首段 WAV 就绪的时间，不含取词、扬声器启动。

| 场景 | 本次耗时 |
| --- | ---: |
| 0.4.7 引擎冷启动 | 17.072 秒 |
| 0.4.8 完成后台预热后 | 0.427 秒 |
| 0.4.8 连续第二次 | 0.414 秒 |
| 0.4.8 英音预热后 | 0.595 秒 |
| 已预热引擎保活 | 0.027 秒 |

后台预热本次耗时 1.927 秒，但在冷启动对照后测量，已有系统文件缓存，不能视为全新机器冷启动。以上是单次测量，不代表所有文本、设备或负载。

生产 OCR 内存管线识别合成中英文图片耗时 0.224 秒，不含屏幕截取和联网翻译。

- 实际 Kokoro 无声预热、美音/英音、保活和临时文件清理通过。

## 复测与取舍

Tests/benchmark_speech.py 接受 --bundle 和 --baseline，分别为 BundledVoice 与 0.4.7 Resources 路径。应用可执行文件支持 --ocr-pipeline-test。使用合成内容，不访问 API Key。

保持模型就绪会增加驻留内存，空闲时不持续推理。启动后立即朗读、资源尚未安装、系统回收进程或高负载时仍可能等待初始化。
