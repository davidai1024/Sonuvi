Sonuvi 0.4.20 使用说明

安装：完整离线 DMG，需要 Apple Silicon Mac、macOS 14.0+，至少预留 3 GB 空间。退出旧版后，把 Sonuvi.app 拖到 Applications，按 Finder 提示替换，并从应用程序打开。

首次使用：跟随引导完成权限、快捷键、音色与语速配置。翻译 API 可以跳过。完整包从内置资源准备英文朗读环境，无需额外安装 Speak11 或下载模型。

朗读：选中英文，按 Option + Shift + S；再次按下可停止。跨应用使用可拖动浮条；翻译窗口内发起的朗读直接显示在窗口底部。提供 28 个美音／英音音色与 0.5–2 倍语速。中文选区会先联网翻译为英文再朗读。

翻译：选中文字按 Option + Shift + T，截图翻译按 Option + Shift + R。设置 → 模型填写自己的 DeepSeek API Key，Key 保存在系统钥匙串。翻译需要网络和有效 API 额度。已有自定义快捷键会保留。

权限：设置 → 权限管理辅助功能与屏幕录制。已授权项目显示已授权。重装后失效时，应用按条件清理自身旧记录一次，重启后回到权限页，由你重新授权。手动修复使用“重新配置权限”。不保证 ad-hoc 签名更新后权限永远保留。

设置：快捷键录制中可用 Esc 或点击外部取消。API Key 编辑可点击外部、Esc 或 Return 结束，草稿保留，保存时才写入钥匙串。通用 → 使用引导可重看首次引导，保留现有配置。

模型：模型正常时显示试听入口。更多菜单提供修复、查看文件和移除。完整包优先从内置资源修复。轻量源码版的联网准备尚未完成全新设备端到端验证。

卸载：退出并删除应用本体不会自动删除已有配置。需要清理 Key、语音环境或统计，可先在相应设置中操作。

边界：仅支持英文语音与 Apple Silicon；跨应用取词依赖目标应用接口。无法划词时可粘贴或截图。当前为个人分享版，ad-hoc 签名，未公证、未上架、无自动更新。

源码、详细功能、截图和最新说明请参阅仓库 README.md 与 CHANGELOG.md。GPL-3.0；第三方来源见 THIRD_PARTY_NOTICES.txt。


首次打开修复
完成拖拽安装后，如果无法打开 Sonuvi，可在 DMG 安装窗口双击“首次打开修复”。工具会校验当前官方应用版本及完整性，仅清除该应用的下载隔离标记，再请求启动。管理员授权只会由 macOS 的系统窗口询问。若脚本自身被拦截，请使用“系统设置 → 隐私与安全性 → 仍要打开”。这不替代正式签名与公证，也不会自动授予辅助功能或屏幕录制权限。
