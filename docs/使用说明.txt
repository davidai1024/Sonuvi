Sonuvi 0.4.3 · Mac 中英划词翻译与自然英文朗读

安装或升级
1. 从旧版 MuseTranslate 或 SpeechTrans 菜单栏退出应用。
2. 将 Sonuvi.app 拖到“应用程序”，再打开。若原来名为 MuseTranslate.app 或 SpeechTrans.app，将旧应用移到废纸篓，避免误开旧版。
3. 原有 DeepSeek Key 保留在系统钥匙串；无需重新填写。
4. 在设置 → 通用检查权限。已授权的项目只显示“圆底勾＋已授权”；未授权时才显示“去授权”。
   辅助功能用于跨应用取词；屏幕录制只用于截图翻译。
   启动、取词失败、打开设置都不会主动申请权限。只有点击“去授权”才发起授权。
   首次点击显示系统授权提示，以后直接进入系统权限页；完成后自动识别状态。
   系统权限与应用路径及签名有关，本版本仍为 ad-hoc 签名，跨版本升级可能需重新授权一次。
   建议固定放在“应用程序”，只运行一份。程序会避免同时运行多个同标识副本。
5. 已安装 Speak11 时，首次启动会导入独立 Kokoro 环境；也可在设置 → 模型手动导入。
   导入完成且显示“独立 Kokoro 已就绪”后，朗读不再依赖 Speak11。

快捷操作
Control + Option + T：翻译选中文字。
Control + Option + R：英文直接朗读；中文先译成英文再朗读。再次按下停止。
Control + Option + O：框选截图，在本机 OCR 后翻译。Esc 取消框选。
鼠标划选或双击选词后出现小浮窗，点击“译”翻译，点击扬声器朗读。
截图适用于图片、扫描 PDF 和不能直接取词的界面。
也可以从菜单栏翻译剪贴板，或打开窗口手动粘贴。
Command + Return：在翻译窗口翻译；Esc 隐藏翻译窗口并取消当前翻译。
原文和结果均支持复制；词典卡的复制按钮复制主要译文。
原文输入框支持 Command+C/V/X/A/Z、Command+Shift+Z：复制、粘贴、剪切、全选、撤销、重做。
在翻译窗口内使用翻译或朗读快捷键时，优先处理选中的文字；没有选区时处理原文。
跨应用取词仍需辅助功能权限。翻译缺少权限、Key 或模型时，在翻译窗口中提示并提供设置入口；朗读错误在小浮条中提示，不会自动打开翻译或设置窗口。

翻译
中文自动译成英文，英文自动译成中文；混合文本根据主要语言判断。
单词与短语显示释义、词性、音标、例句；句子流式显示译文。
窗口右上角 Aa 菜单提供“自动 / 单词 / 句子”、粘贴翻译与截图翻译。切换展示方式后重新点击翻译。
原文输入区按实际换行自适应高度，最高 180 点；超过后在框内滚动，删减文字后自动缩回。
翻译浮窗采用紧凑原文卡片、自动语言栏、始终展示的 DeepSeek 结果卡。
语言栏中间的交换按钮会把当前译文作为原文再次翻译；生成中或尚无译文时不可用。
原文、译文和例句各自提供朗读操作；本地模型目前仅支持英文，中文侧的朗读按钮不可用。
右上角关闭按钮和 Command + W 隐藏翻译窗口，应用继续在菜单栏运行。
单次最多 6000 个字符；最新 100 条结果只在内存缓存，退出即清除。
默认 DeepSeek deepseek-flash，关闭思考。可在模型设置中修改模型名称。
连接失败或部分可重试错误自动重试一次；已收到的部分输出不会自动重发。
释义、音标及例句来自 AI，可能有误，不是权威词典的逐条查询结果。

朗读与模型
Kokoro 82M 在 Apple Silicon Mac 本机运行，准备好后可离线使用。
五种美音/英音音色，语速 0.5–2 倍，可试听、自动朗读、随时停止。
朗读选区时只显示独立毛玻璃小浮条，不打开翻译窗口。左侧六点手柄可拖动，右侧停止按钮会停止并收起；播放结束自动收起。
中文先翻译成英文的等待阶段也可停止。错误提示五秒后自动收起，可悬停查看完整内容。
较长文本分段合成播放；停止后不再播放后续片段。
设置 → 模型支持导入现有 Speak11 环境、联网下载、查看文件、移除独立环境。
首次导入/下载至少预留 2.5GB 空间。安装过程中可取消，完成后再切换到新环境。
联网下载需访问 Python、PyPI、GitHub 和 Hugging Face；网络受限时可导入现有环境。
移除只处理 Sonuvi 自己的 Voice 目录，移到废纸篓；不会卸载 Speak11、删除 Key 或清空统计。
如独立模型尚未准备好但 Speak11 已安装，暂时使用 Speak11 的本地环境作为过渡。

设置和界面
六组设置：通用、翻译、朗读、模型、统计、快捷键。
支持跟随系统、浅色、深色。窗口轮廓由 macOS 原生窗口统一绘制，背景使用系统毛玻璃；macOS 26 的侧栏和控件保留原生 Liquid Glass。
设置窗口可调整大小，卡片/图表自动排版，内容区独立滚动。
支持登录启动、窗口置顶、隐藏指定应用的划词按钮、控制复制取词回退。
登录启动需先把应用放入“应用程序”；系统若要求后台项目批准，请在系统设置中完成。
全局快捷键可以录制修改；重复或被占用时会明确提示，并保留原有注册。
快捷键录制成功后立即生效并保存；重复或占用时保留原配置。其他设置仍点击“保存设置”，Command + S 也可保存。
菜单栏含今日用量、连续使用天数、28 天点阵、翻译、朗读、截图、剪贴板翻译、外观切换、统计和设置。
快捷键使用系统菜单原生右侧列；设置侧栏使用彩色图标和悬浮圆角玻璃层。
应用、翻译窗口、设置和菜单栏使用用户提供的 SpeekyTrans 原始图标资源。

本机统计
累计翻译次数、查词/短语次数、句子次数、处理词数、朗读次数与词数、使用应用数、活跃天数。
显示完成播放的听读时长，以及窗口在前台、最近 60 秒内有交互的主动使用时长。
主动时长为按 15 秒采样的近似值，不把后台常驻时间计入；没有追溯旧版本历史。
每日柱状图支持 7 天和 30 天，指针移到柱形上可查看当天详情。
90 天发光点阵每个点对应一天，亮度按当天翻译和朗读次数变化，空白天不虚构活动。
指针悬停可查看日期和次数；点阵按从左到右、从上到下的时间顺序排列。
“迈出第一步”“百词有获”“日日有进”“听见一小时”按本机记录达成。
连续使用成就按历史最长连续天数判断。
统计在成功返回翻译（包括内存缓存）或完整播放朗读后累计；重试、失败、取消不多计。
词数使用系统分词，中文按分词结果计数；查词次数代表查词操作，不代表不同词的数量。
应用数按来源应用标识去重；手动输入和剪贴板操作不推断来源应用。
可关闭统计或清空统计；清空时原文件移到废纸篓。

隐私
Key 持久保存在 macOS 钥匙串，主动翻译读取成功后仅在当前进程内缓存，避免重复读取提示。程序不会把 Key 写进日志、统计或进程参数。
只有主动翻译或开启自动朗读后的翻译动作才向 DeepSeek 发送原文；鼠标划选本身不会发送。
自动朗读仅在完成翻译后工作，不会自动扫描屏幕内容。
OCR 在本机识别；临时截图在完成、失败或取消后删除。识别出的原文仅在翻译时发送 DeepSeek。
朗读在本机完成；音频临时文件在播放后清理，闲置的语音服务约 10 分钟后退出。
统计只保存日期、计数、时长与来源应用标识，不保存原文、译文或音频，不上传统计。
为兼容旧版，数据继续位于 ~/Library/Application Support/MuseTranslate/Usage.json；语音环境在其中 Voice 子目录。应用标识和钥匙串标识保持不变，无需迁移设置、Key、统计或模型。

验证与边界
0.3.6 调整翻译窗口视觉层级：语言栏去底色、使用 11 pt 常规灰字；DeepSeek 标题缩为 11 pt 灰色标签，移除展开收起；原文占位为 13 pt、译文占位为 11 pt，使用系统三级文字色。正文维持原尺寸。
0.3.5 已完成编译和 48 项核心回归检查。
原生输入框已实测全选、复制、粘贴、剪切、撤销、重做；设置标题栏已检查深浅色。
修复取词权限不足、缺少 Key 时强制打开设置的分支；调整激活顺序，操作窗口在应用激活后成为键盘焦点。
设置窗口使用透明原生标题栏，系统红绿灯内嵌悬浮侧栏，内容为按钮预留空间。
应用前台的原生操作菜单与菜单栏菜单共用翻译、朗读和截图处理方法；全局快捷键仍由 Carbon 注册。
本轮自动化输入未可靠触发跨应用 Carbon 热键，不能把菜单操作检查等同于实体键盘端到端验证。
安装后请在其他应用选中英文，用设置中显示的翻译和朗读快捷键验证；若提示取词权限未授权，需在系统设置允许当前安装路径的 Sonuvi。
不能保证每个应用都允许直接取词。优先辅助功能读取，显式操作时可复制取词；失败可截图。
本轮未重复验证真实 DeepSeek 请求、全部音色、多显示器、登录启动或全新模型下载。
本版仅面向个人本机使用，ad-hoc 签名，未做公证、自动更新或 App Store 分发。

源码与许可
Source 目录为完整对应源码、测试和构建脚本。需要 Xcode Command Line Tools，Apple Silicon。
执行 bash build.sh 重建；资源中已附 uv 与许可证，构建时无需下载模型。
如本机有固定代码签名证书，可用 MUSE_SIGNING_IDENTITY 指定同一个身份来构建后续版本。
构建脚本不修改系统信任设置，也不降低应用的签名身份校验要求。
独立实现取词与 UI，复用 Easydict 的翻译提示词并修改，非官方 Easydict 改名版。
GPL-3.0；见 LICENSE、THIRD_PARTY_NOTICES.txt 和 uv 许可证。

卸载
从菜单栏退出，删除应用即可。需要删除 Key 时，先到设置 → 模型中删除。
需要清理语音环境、统计时，分别使用对应管理按钮。

0.4.1 界面更新
统计页和菜单摘要新增绿色流动点阵。统计页按实际词数展示下一里程碑进度，菜单按最近七天活跃天数展示；动画只改变亮度，不改变统计值。
菜单顶部按内容高度排布，收紧留白；操作和快捷键仍使用系统原生菜单。关闭页面或菜单后停止动画，开启减少动态效果或低电量模式时显示静态点阵。

0.4.1 交互更新
• 点击划词浮动菜单的翻译或朗读后立即收起，并取消旧的选区检测，避免重新弹出。
• macOS 原生文本服务：在支持的应用中选中文字，右键 → 服务 → 用 Sonuvi 翻译／用 Sonuvi 朗读。某些应用也在应用名称 → 服务中提供入口；应用不支持文本服务时仍可使用全局快捷键。
• 翻译窗口内发起的朗读在底部状态栏显示点阵和停止按钮，不再弹出外部朗读条。
• 跨应用划词、全局快捷键或系统服务发起的朗读仍显示可拖动浮条。
• 点阵读取原生播放器的实时音量，随语音起伏，停顿变暗；停止或结束会清空播放状态。
• 更新后若系统服务暂未显示，可重开目标应用；也可在系统设置 → 键盘 → 键盘快捷键 → 服务中检查对应条目。

划词检测要求新的外部鼠标按下事件；菜单点击后的残留双击抬起事件不会再次打开菜单。

0.4.2 设置窗口更新
原生红绿灯按参考图内嵌悬浮侧栏：中心距窗口顶部和左侧 26 点，按钮中心间距 23 点。保留系统按钮的悬停、关闭、最小化及缩放行为；窗口缩放时维持定位。

0.4.3 翻译窗口背景
macOS 26 使用原生液态玻璃，旧版 macOS 使用原生菜单毛玻璃材质。去掉整窗厚底色，保留原文和译文卡片的轻微底色区分。
