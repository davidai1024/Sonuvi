# 原文输入与冻结截图修复

2026-10-23，0.4.33 测试分支；尚未发布。

原文编辑保留 AppKit 输入法组合文本，仅在提交后同步模型；外部替换等待候选词结束。撤销、重做同步绑定。布局测量合并到下一轮事件循环，未变化的尺寸不重复全量布局；语言检测延迟 200ms，立即翻译仍同步读取最新文本。

截图先取得整个桌面的静态图像，再创建框选窗口。框选背景和 OCR 裁剪共用这一图像，不再读取菜单关闭后的桌面。macOS 15.2+ 使用 ScreenCaptureKit，较旧系统使用非交互 screencapture；临时文件在读取后删除。屏幕配置变化取消操作。

固定证书构建通过。验证：核心 109 项、编辑 26 项、选区 98 项、翻译布局 14 项；OCR 冻结裁剪/双语识别/取消测试通过。5000 行原文末尾 30 次原生编辑约 185ms；模型连续 30 次编辑约 2ms（本机合成测试，非真实打字端到端延迟）。

限制：尚未对具体应用的弹出菜单进行实机端到端验证；多显示器只验证合成坐标，未验证真实混合缩放屏幕；较旧 macOS 截图分支尚未运行。用户需要在菜单展开时使用截图快捷键；若先点击其他位置使菜单在截图命令前关闭，无法恢复此前内容。此文档不改变划词兼容性报告中的发布验收状态。
