# Sonuvi 0.4.11 · 划词菜单修复

本版本延续 0.4.10 的权限返回、自动重启与钥匙串处理。

## 修改
- 被动划词从鼠标落点和焦点控件读取选区，最多向上检查四层，补上网页/聊天控件选区不在焦点元素上的情况。
- Electron 应用按官方文档按需开启 AXManualAccessibility；不启用 VoiceOver，不重置系统权限。
- AX 工作队列支持取消过时请求；单次查询有时间预算，避免快速连续划词积压。
- Sonuvi 原文框支持选区菜单；处理 NSTextView 自身追踪循环消耗鼠标松开事件的情况。
- 原文框中英文选区朗读保持内嵌播放，不用选区覆盖完整原文。
- 菜单提高层级，避免被源应用浮动窗口盖住；滚动、点击其他位置和执行操作时隐藏。
- 返回 Sonuvi 时重装监听器，同时保留当前有效手势，避免激活时把选区丢掉。
- 快捷键继续读取键盘焦点，不使用可能指向别处的鼠标落点。

## 验证范围
- 101 项核心检查、39 项划词状态与读取路径回归、10 项原生文本控件测试。
- 新增场景包括：缺少焦点、父级选区、过时焦点优先级、循环节点、时间预算、取消、原文选区范围、空白区域和字段编辑器排除。
- 尚未获得用户具体复现应用，未实测所有第三方应用；未读取用户选中文字或剪贴板来验证。
- 某些应用不提供辅助功能选区，仍需用快捷键取词或截图翻译。

## 安装
先退出旧版，将 Sonuvi.app 替换到应用程序，再启动。更新包沿用本机模型，不需要重新下载模型。
本版本仍为 ad-hoc 签名，如 macOS 要求重新授权，应在系统设置中给新版授权；不自动清除已有授权。
对应源码与构建脚本位于包内 Sonuvi-v0.4.11-Source.zip。
