independently authored UI and query routing. The compact query layout in

Speak11 — https://github.com/smcantab/speak11
Unlicense (upstream). An original Unix-socket client can access the user's
existing installation as a transitional fallback. The user may import a local
copy of their existing environment into Sonuvi-owned storage.
Speak11 source is not included. The full offline edition contains independently
owned Python dependencies and model files; it does not require Speak11. The
new local service and installer are independent implementations.

Source available from the upstream project and its 0.12.5 release/tag.
uv bootstraps a Python runtime when no existing Python is available.

Kokoro — https://huggingface.co/hexgrad/Kokoro-82M
MLX conversion — https://huggingface.co/mlx-community/Kokoro-82M-bf16
Pinned model revision: a71e4d38b236d968966a2002c4c895dbd12b1c3c.
The full offline edition includes model weights at the pinned revision and
all 28 English voice files. The MLX model card declares Apache-2.0; its card,
license text and attribution accompany the payload. The lightweight edition
downloads weights on demand or imports them from an existing local cache.
The optional installer obtains MLX Audio, MLX, Misaki, spaCy, en_core_web_sm,
soundfile, phonemizer-fork, espeakng_loader and supporting dependencies from
upstream package/model sources; their licenses and package metadata remain
with the runtime. The full offline edition includes these Python/native dependencies and a
standalone CPython runtime; individual package licenses and metadata remain
in their distribution directories. A package/version inventory is included
in BundledVoice/dependencies.json. No private application state is included.

Apple native frameworks
AppKit, SwiftUI, Vision, Charts, NaturalLanguage, ServiceManagement,
ApplicationServices, Carbon, CoreText, and Security are supplied by macOS.
Liquid Glass uses native macOS 26 APIs; older systems use native materials.

DeepSeek — https://api.deepseek.com
User-provided API key stored in macOS Keychain. Translation actions send the
source text to the official API. Selection itself only displays a local action
button. Usage counters are local aggregates and are not uploaded.
